서비스 로그인 → Riot 경기 선택 → MP4 업로드 → 분석 리포트

1. 서비스 계정 로그인

아래 계정은 LOLDOV의 로컬 테스트용 로그인입니다. Riot 계정 비밀번호는 입력하지 마세요.

2. Riot ID 최초 등록

Riot ID를 등록하면 API로 경기 기록을 조회합니다. 계정 소유권을 인증하는 Riot RSO 로그인은 아닙니다.

3. 대전 기록에서 경기 선택

이번 단계에서 경기를 선택하면 Match ID·챔피언·패치가 자동 전달됩니다. 영상과 동일한 경기를 선택해야 해요.

4. 동일 경기 MP4 영상 업로드

현재는 로컬 PC에서 동작합니다. 2GiB 이하 MP4. 기본 모드는 Riot+RAG 코칭 5건이며 유료 Gemini 호출이 발생합니다. 시간 OCR이 불확실하면 타임라인 사건 연결 없이 코칭합니다.

5. 분석 진행 및 결과

연구용 로컬 프로토타입입니다. Riot RSO 인증·상용 인증 보안·자동 동일 경기 검증 및 OCR 동기화 보장은 제공하지 않습니다.
